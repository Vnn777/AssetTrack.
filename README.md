# AssetTrack — Gestão de Patrimônio de TI

Sistema de inventário de equipamentos de TI desenvolvido com Python, Flask, SQLite, HTML, CSS e JavaScript.

## Funcionalidades

- Dashboard com indicadores de patrimônio
- Cadastro, edição e consulta de equipamentos
- Busca e filtros
- Movimentações e histórico
- Exportação CSV

## Execução local

```bash
pip install -r requirements.txt
python app.py
```

Abra a aplicação na porta 5000.

**Atenção:** versão de portfólio. Para uso corporativo, implementar autenticação, autorização, proteção CSRF e configuração de banco persistente.
